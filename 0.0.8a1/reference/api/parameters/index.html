    Parameters¶

    helab.analysis.parameters ¶

    Parameters an analysis declares: defaults, limits and units, validated before a run.

    A choice parameter picks one of its choices and a text one holds free text the analysis reads itself (e.g. mask circles, masks); another parameter can say it applies only under one of them (when, and shown_with for a condition on several), so the parameter tree shows it only then and the dock's source line leaves it out otherwise. group names the tree section it sits in, and page the settings tab (a plot whose parameters name more than one page gets a tab each).

    Kind module-attribute ¶

    Kind = Literal['float', 'int', 'bool', 'choice', 'text']

    A parameter's type: a number, a switch, one of choices, or free (multi-line) text.

    SI_FACTORS module-attribute ¶

    SI_FACTORS = {
    "G": 1000000000.0,
    "M": 1000000.0,
    "k": 1000.0,
    "": 1.0,
    "m": 0.001,
    "µ": 1e-06,
    "n": 1e-09,
}

    The SI prefixes ParameterSpec.unit_prefix may name, with their factors.

    Value module-attribute ¶

    Value = float | int | bool | str

    A parameter's value: a plain JSON value.

    ParameterSpec dataclass ¶

    ParameterSpec(
    name: str,
    title: str,
    kind: Kind,
    default: Value,
    limits: tuple[float, float] | None = None,
    suffix: str = "",
    tip: str = "",
    choices: tuple[str, ...] = (),
    group: str = "",
    when: tuple[str, str] | None = None,
    si: bool = False,
    page: str = "",
    unit_prefix: str | None = None,
    shown_with: Callable[[Mapping[str, Any]], bool]
    | None = None,
)

    One parameter an analysis declares (DatasetAnalysis.parameters).

    Example

    ParameterSpec("bins", "Bins", "int", 100, (10, 10_000), tip="Histogram bins.")

    Attributes:

    • name (str) –

      The key the analysis reads in context.parameters.

    • title (str) –

      What the plot's settings show.

    • kind (Kind) –

      The type (Kind).

    • default (Value) –

      The value when none is set.

    • limits (tuple[float, float] | None) –

      (min, max) a number is clamped to; None for no limits.

    • suffix (str) –

      The unit shown after a number (e.g. " %", " s").

    • tip (str) –

      The tooltip in the plot's settings.

    • choices (tuple[str, ...]) –

      For kind "choice": the allowed values, shown as a drop-down.

    • group (str) –

      The settings section it belongs to ("" for the top level).

    • when (tuple[str, str] | None) –

      (choice parameter, value): the parameter applies only while that choice parameter has that value; None for always.

    • si (bool) –

      A float in a base unit (s, m), shown with SI prefixes (4 mm) and stepped by decade.

    • page (str) –

      The settings tab it is on ("" for the first); a group goes on its first parameter's page.

    • unit_prefix (str | None) –

      With si, the one SI prefix the value is always shown with ("m": a T in s shown in ms), its digits grouped by thousands; the value itself stays in the base unit. None: the prefix follows the value.

    • shown_with (Callable[[Mapping[str, Any]], bool] | None) –

      A further condition on all the values, beside when: the parameter applies only while it holds too. Not compared.

    coerce ¶

    coerce(value: Any) -> Value

    value as this parameter's type, clamped to its limits (a choice outside choices becomes the default).

    applies ¶

    applies(values: Mapping[str, Any]) -> bool

    Whether this parameter is in use under values (its when holds, or it has none).

    tree_item ¶

    tree_item(value: Any = None) -> dict[str, Any]

    A pyqtgraph Parameter definition.

    text ¶

    text(value: Any) -> str

    title value suffix for a source line.

    effective ¶

    effective(
    specs: Sequence[ParameterSpec],
    values: Mapping[str, Any] | None = None,
) -> dict[str, Any]

    Every declared parameter, from values where given, else its default; unknown keys dropped.

    describe ¶

    describe(
    specs: Sequence[ParameterSpec],
    values: Mapping[str, Any],
    every: bool = False,
) -> str

    title value suffix pairs for a source line, in declaration order: the parameters in use under values (every: all of them, for the record).

    tree_children ¶

    tree_children(
    specs: Sequence[ParameterSpec],
) -> list[dict[str, Any]]

    pyqtgraph Parameter definitions, grouped by group in declaration order.

    unused_parameters ¶

    unused_parameters(
    specs: Sequence[ParameterSpec],
    values: Mapping[str, Any],
) -> frozenset[str]

    The names of the parameters not in use under values (ParameterSpec.applies: hidden by their when or shown_with), which a result's reuse key leaves out (a setting the run didn't use never makes its result look different).
