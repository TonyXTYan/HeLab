    Fits¶

    helab.analysis.fits ¶

    Bounded least-squares fits of 1D histograms, for the T/X/Y fits of the DLD port.

    fit_histogram(centres, counts, model) fits one of the registered MODELS with scipy.optimize.curve_fit and returns a FitResult: each parameter's value ± SE (from the covariance), the model curve, χ² per degree of freedom and, when the fit can't be trusted, a failure reason. Failures (no data, too few points, everything in one bin, no convergence, an undetermined parameter) are results with a note, never exceptions, so a plot can say why it shows no fit.

    How a fit runs: - Input: raw counts per bin, or anything else with its errors given as sigma= (rates, smoothed counts). The count weights assume whole-number counts and say so otherwise. - Weights: counts are Poisson. weights="poisson" (the default) first fits with each bin's error √max(n, 1), then refits with the model's own variance until the parameters settle: the Poisson maximum-likelihood fit (_reweight says why: the first fit alone biases widths low). "counts" stops after the first fit. Either way the covariance is absolute (the SEs don't scale with χ²; a poor model shows as a large reduced χ², noted). "none" fits unweighted and scales the covariance by the residuals instead. - Offset: for counts (nonnegative_offset; by default raw counts with count weights) a model's offset is at least 0 (a mean count can't be negative), and an offset at 0 isn't noted as "at its bound"; otherwise (sigma= rates, background-subtracted data) it keeps the model's bound, −top. - Bins: by default (binned) the model is averaged over each bin (five-point Gauss–Legendre, bin_means), not taken at its centre: a centre value biases a width by about +w²/(24σ) for bins w wide (Sheppard's correction: +0.5 SE at 50 000 events in bins of σ/5, several SE at 10⁵–10⁶). Bin edges are edges= when given, else halfway between neighbouring centres, which assumes equal-width bins of counts. binned may be a weight function w(x) (r² for radial shells): each bin then gets ∫w·f / ∫w. The result's curve and evaluate are the model itself at points (not averaged), for drawing. - Scaling: x and counts are mapped to order one before fitting (a T profile is ~0.4 s wide ~0.1 ms, counts ~10³), each parameter by its role (a position, a width, a height or a dimensionless shape), and mapped back with the covariance. - Starting points come from moments (each model's guesses); a model may give several, and the converged one with the lowest χ² is kept. - Components: a parameter that only shapes one part of a model (a TF radius) names that part's amplitude as its gate. When the amplitude is consistent with 0 (within 2 SE) the fit says so in a note and the parameter's SE is nan, instead of failing.

    Models are derived from the physics, not copied from the MATLAB code (which has bugs). Registered now: Gaussian + offset, the Thomas–Fermi projection (1 − u²)^p + offset, bimodal TF^p + Gaussian with a shared centre, and the exact arrival-time ("Yavin") thermal profile on T (arrival_time_model), and the Bose-enhanced thermal profiles g_{5/2} and g_2 (bose_model, with polylog) and the bimodal TF² + g_{5/2} and TF^{3/2} + g_2 (fugacity 1). condensate_fraction and component_areas give N0/N and the parts' areas ± SE from a fit's covariance; helab/analysis/bec.py turns them into BEC properties and sets the R/σ_th cap per axis. Pure NumPy/SciPy, no Qt. Fits run in the analysis worker thread, so nothing here changes warning filters per call (warnings.catch_warnings isn't thread-safe).

    bin_means ¶

    bin_means(
    function: Callable[..., Array],
    lower: Array,
    upper: Array,
    values: Sequence[float] | Array,
    weight: Callable[[Array], Array] | None = None,
) -> Array

    function(x, *values) averaged over each bin [lower, upper] by five-point Gauss–Legendre quadrature (exact for polynomials up to degree 9; for a Gaussian in bins of σ its error is ~10⁻¹⁰ of the peak, against the centre value's ~4 %). With weight w(x), the weighted mean ∫w·f / ∫w (radial shells: w = r²), both by the same quadrature.

    fit_histogram ¶

    fit_histogram(
    centres: ArrayLike,
    counts: ArrayLike,
    model: str | FitModel = "gaussian",
    *,
    weights: Weights = "poisson",
    sigma: ArrayLike | None = None,
    max_evaluations: int = MAX_EVALUATIONS,
    max_radius_ratio: float = MAX_RADIUS_RATIO,
    covariance_of: Callable[[Array, Array, Array], Array]
    | None = None,
    nonnegative_offset: bool | None = None,
    binned: bool | Callable[[Array], Array] = True,
    edges: ArrayLike | None = None,
) -> FitResult

    Fit model (a MODELS key or a FitModel) to a histogram's bin centres and raw counts. sigma, when given, is each bin's error (absolute) and replaces weights: pass it for anything that isn't raw counts. Bins with a non-finite centre, count or error, or an error ≤ 0, are left out (noted).

    max_radius_ratio caps R/σ_th in models with a ratio parameter (bimodal; see bimodal_model for why 2, and when to raise it). A fit that ends at the cap says so; the cap goes in the result's options and record.

    covariance_of(x, values, fitted), when given, replaces the fitted parameters' covariance (data units, from the weights alone) before anything reads it: the SEs, the "consistent with 0" gating and its notes, the undetermined check and the extras. For data whose bins are correlated (a smoothed curve: profiles.fit_smoothed), where only the caller knows the real spread; x are the bins fitted.

    nonnegative_offset: the offset is at least 0 (counts); None means so for raw counts with count weights (no sigma, weights not "none"). binned: the model is averaged over each bin; False takes it at the centres (point samples, or a model that already integrates its bins); a function w(x) averages with that weight, ∫w·f / ∫w (radial shells: r²). edges (len(centres) + 1, in the centres' order) are the bins' exact bounds, used whenever given; without them the edges are halfway between the centres given (before any are left out), which is right for equal-width bins of counts only.

    bimodal_model ¶

    bimodal_model(
    power: float, bose: float | None = None
) -> FitModel

    A condensate on a thermal cloud, one centre: A_c (1 − u²)₊^p + A_t exp(−(x − x₀)²/2σ²) + offset, u = (x − x₀)/R, R = r σ with r = R/σ from MIN_RADIUS_RATIO up to the fit's max_radius_ratio. R is reported as an extra. Started from a Gaussian fit (count weights, or the caller's errors), split four ways (the last a cold cloud's, clipped to the cap).

    bose (the polylog order, 5/2 or 2) makes the thermal part the Bose-enhanced A_t g_ν(e^{−(x − x₀)²/2σ²}) / ζ(ν), its fugacity fixed at 1 (see bose_thermal).

    polylog ¶

    polylog(order: float, x: ArrayLike) -> Array

    Li_order(x) for real x in [0, 1] (clipped to it) and order > 1: the Bose functions g_ν.

    offset: float,

    bose_area ¶

    bose_area(
    amplitude: float,
    sigma: float,
    fugacity: float,
    order: float = 2.5,
) -> float

    ∫ A g_ν(z e^{−u²/2σ²}) / g_ν(z) dx = A √(2π) σ g_{ν+1/2}(z) / g_ν(z) (1 as z → 0).

    bose_model(order: float) -> FitModel

    The Bose-enhanced thermal profile g_ν + offset, its fugacity z fitted in [0, 1]. Started from a Gaussian fit, at three fugacities (σ wider as z grows: the enhanced centre is narrower).

    condensate_fraction ¶

    condensate_fraction(fit: FitResult) -> Estimate

    N0/N = A_TF / (A_TF + A_thermal) from a bimodal fit's component areas, ± SE by the delta method on the fitted parameters' covariance (so the areas' correlation is counted). nan for a failed fit or a model without a condensate part. The fraction is of the counts the histogram holds: a cropped box or window crops the thermal wings more than the condensate. On a slice model (FitModel.slice: TF^{3/2}, g_2) it is the slice's fraction, not the cloud's (a thin central slice holds relatively more condensate); the fit's notes say so (SLICE_NOTE).

    bose_order ¶

    bose_order(power: float) -> float

    The Bose order that integrates the same axes as the TF exponent: 5/2 for p = 2, 2 for 3/2.

    acceptable ¶

    helab.analysis.profiles ¶

    T/X/Y profiles for the histogram plot: display units, rates per shot, Gaussian smoothing, and the fits with their temperatures.

    The units and the rate method follow the MATLAB front panel's dld_plot_tof.m, with its bug fixed: - Axes: X and Y in mm, T in ms (display_units). - Rates: counts / bin width / number of shots, after the view range (and, when chosen, the whole box) has picked the events: T in kHz per shot (per ms), X and Y per mm per shot (the front panel divided X and Y by the bin width only). - Smoothing (optional): a Gaussian of σ over bins of σ/5 (the front panel's bin_factor). Fits use the unsmoothed counts unless the smoothed curve is chosen.

    Fits are in the data's own units (s, m) on counts per bin; drawing scales the fitted curve by the same factor as the bars. No Qt and no I/O: runs in the analysis worker and in tests.

    Smoothing ¶

    Smoothing(bins: int, sigma_bins: float)

    The smoothing of bins bins with a Gaussian of sigma_bins bins, as the linear map s = S n (a sparse matrix): each bin's counts spread by the kernel, the edges reflected (the bins beyond an edge mirror those inside, np.pad's "symmetric"), so what spreads past an edge folds back in and every column sums to 1: the total is kept. The same S smooths what is drawn and, in a fit of the smoothed curve, the model (fit_axis).

    apply ¶

    apply(values: ArrayLike) -> Array

    values (one per bin) smoothed: S · values.

    variance ¶

    variance(mean_counts: ArrayLike) -> Array

    Each smoothed bin's variance when the raw bins are Poisson with these means: Σⱼ Sᵢⱼ² μⱼ.

    covariance_times ¶

    covariance_times(mean_counts: Array, block: Array) -> Array

    S diag(μ) Sᵀ · block: the smoothed bins' covariance (they share raw counts) times a matrix, without forming the (bins × bins) covariance.

    mu_consistency ¶

    mu_consistency(
    axis: Axis,
    constants: ResolvedConstants,
    bin_width: float,
    shots: int | None,
) -> Consistency

    fits.choose_condensate's check of a bimodal fit against the constants: μ/k_BT from its R/σ_th (R/σ = √(2μ/k_BT) λ(t_f)/√(1 + ω²t_f²) on this axis's trap axis: bec.radius_ratio_cap at μ/k_BT = 1 is √2 times that factor) against bec.from_fit's μ/k_BT from N0 and T, within fits.MU_AGREEMENT.     fit_axis ¶

    fit_axis(
    axis: str,
    edges: ArrayLike,
    counts: ArrayLike,
    choice: str,
    constants: ResolvedConstants,
    smoothing: float | None = None,
    max_radius_ratio: float | None = None,
    shots: int | None = None,
) -> AxisFit

    Fit one histogram (edges in s or m, raw counts) with the model choice names.

    By default the raw counts, Poisson weighted (fit_histogram). smoothing (σ in the data's units) fits the smoothed curve instead, with the smoothing in the model (fit_smoothed): the parameters are the unsmoothed profile's, so the width (and a bimodal fit's R) needs no correction, and the SEs count the smoothed bins' correlation. Temperatures are the ideal-gas, pure-expansion ones (physics): along T σ_v = g σ, along X and Y σ_v = σ / t_f, each with the run's constants. max_radius_ratio: the bimodal fits' cap on R/σ_thermal (fit_histogram); None (the default) takes this axis's physical cap at μ/k_B T ≤ 2 (axis_cap: the trap frequencies, the fall time and which detector axis is the trap's long one), or fits.MAX_RADIUS_RATIO when those don't give one.

    The bimodal TF + Bose choices also fit the free-z Bose profile and report a condensate only when that one saturates and the bimodal fit is clearly better (fits.choose_condensate); otherwise the result is the free-z fit, with "no condensate (z = …)" in the notes. With shots (the shots the histogram sums), an unsaturated case is also checked against the constants (mu_consistency). A smoothed-curve fit makes that decision on the unsmoothed counts (two more fits: correlated smoothed bins inflate Δχ² several times) and shows the smoothed fit of the model it chose.

    smoothed_model ¶

    smoothed_model(
    model: FitModel, smoothing: Smoothing, centres: Array
) -> FitModel

    model with the smoothing applied to its prediction on the bins (centres), the model averaged over each bin (fits.bin_means): S·f̄(θ). Anywhere else (a finer grid, as FitResult.evaluate draws) it is the unsmoothed model: S belongs to those bins only.

    fit_smoothed ¶

    fit_smoothed(
    centres: Array,
    raw: Array,
    model: FitModel,
    sigma_bins: float,
    max_radius_ratio: float = MAX_RADIUS_RATIO,
) -> tuple[FitResult, Array]

    Fit the smoothed counts s = S n with the smoothed model S f(θ) (smoothed_model), and the smoothed fit's curve on the bins.

    • Weights: each smoothed bin's variance from the model, Σⱼ Sᵢⱼ² μⱼ with μ = f(θ) (floored as fits.VARIANCE_FLOOR per raw bin), refitted up to SMOOTHED_ROUNDS times until θ settles. The first fit uses the observed counts' (S² n); weights from observed counts alone would bias low-count fits.
    • SEs: the smoothed bins share raw counts, so their covariance is S diag(μ) Sᵀ, not diagonal. Each fit's covariance is the sandwich (JᵀWJ)⁻¹ JᵀW S diag(μ) Sᵀ WJ (JᵀWJ)⁻¹, with J the smoothed model's derivatives and W the weights: what the estimator's spread really is. It goes to fit_histogram (covariance_of), so the SEs, the "consistent with 0" gating and its notes, the undetermined check and the extras (a bimodal R) all use it.
