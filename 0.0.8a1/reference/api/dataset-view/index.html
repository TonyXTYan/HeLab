    Dataset view¶

    A DatasetView is the one input an analysis gets: compute reads it as context.view. It is a read-only, immutable snapshot of the data a folder tab has loaded. Its arrays are shared with HeLab and with other runs, and NumPy refuses writes to them: call .copy() before changing one.

    Each shot is an Events array of shape (n, 3): T in seconds since the trigger, and X and Y in metres. events(shots) joins chosen shots into one new array; txy gives a shot's T/X/Y columns.

    While HeLab follows a folder live, each batch of new shots makes a new revision of the view (revision, added_shots), with the same identity (identity).

    A read-only, immutable snapshot of a loaded dataset: the one input an analysis gets.

    compute reads it as context.view. Its arrays are shared with HeLab and with other runs, and read-only: copy one (.copy()) before changing it. A view may have no shots (Live started before the folder's first shot); a plot then says it is empty.

    Attributes:

    • identity (ViewIdentity) –

      Which data this is (ViewIdentity).

    • revision (int) –

      1 for a loaded dataset, one more each time a newer load (Live's) adds or replaces shots, or only finds their raw files' times.

    • shots (Mapping[int, Events]) –

      Shot number → that shot's events, a read-only (n, 3) T/X/Y array (Events), in ascending shot order. events joins chosen shots into one array.

    • fingerprints (Mapping[int, Fingerprint]) –

      Shot number → its TXY file's Fingerprint.

    • provenance (Provenance) –

      Where the data came from (Provenance).

    • data_root (DataRootRef | None) –

      The data root the folder is under, when known.

    • added_shots (tuple[int, ...]) –

      The shots this revision added or replaced (a replaced shot's array is new: its TXY file was rewritten, or it now comes from another TXY). A revision that only found shot times has none. A running total over revisions must take a replaced shot's old events out before adding its new ones.

    • created_at (float) –

      When the view was made (wall-clock time).

    • dataset_signature (str) –

      The signature of the loaded dataset this revision is ("": the identity's, as at revision 1).

    • raw_times (Mapping[int, int]) –

      Shot number → its raw d<N>.txt file's mtime in ns, where one was found (shot_time reads it).

    • origins (Mapping[int, str]) –

      Shot number → its origin, helab:<profile hash>, for shots read from HeLab's own TXY; shots from MATLAB's TXY aren't listed.

    • txy_profiles (Mapping[str, Mapping[str, Any]]) –

      Profile hash → its name, version and whether it is calibrated, for the HeLab TXY in the view.

    • on_read (frozenset[int]) –

      The HeLab shots converted from their raw files when they were read.

    • fallback (frozenset[int]) –

      The shots read from beyond the TXY choice's own list, because none of its entries had them: from its fallback (the folder's or Settings' list, External, then any HeLab TXY). origins says which TXY each is.

    • txy_choice (str) –

      The TXY choice the data was loaded with ("": none named, MATLAB's TXY alone). Views of two choices are never revisions of each other.

    helab.analysis.dataset_view.ViewIdentity dataclass ¶

    ViewIdentity(
    source_path: str,
    root_key: str,
    signature: str,
    source: str = "",
    chain: str = "",
)

    Which data a view is: its folder, the load and the TXY it is made of.

    Two views with the same identity are revisions of one chain (DatasetView.revision); a fresh load, another TXY choice or another profile is another identity.

    Attributes:

    • source_path (str) –

      The folder the data was loaded from.

    • root_key (str) –

      The folder's data-root key, root://<uuid>/<relative>; "" when no data root (.helab-root) is known.

    • signature (str) –

      The loaded dataset's signature (a hash of its TXY files' fingerprints); "" when it has none (e.g. a resumed partial load).

    • source (str) –

      Which TXY source the data is made of: "" for the two priority modes (the shots' DatasetView.origins tell their data apart), else the mode's name or the TXY priority list's text (txy_sources.identity_source).

    • chain (str) –

      The token of this chain of revisions ("" for a placeholder view). Not part of a result's reuse key, which compares the data itself.

    name property ¶

    name: str

    The folder's name (the last part of source_path), for titles and records.

    helab.analysis.dataset_view.Provenance dataclass ¶

    Provenance(
    source: str,
    loaded_at: float | None,
    checked_at: float | None,
    verified: bool,
    unsettled_files: int,
    failed_files: int,
    problematic: tuple[int, ...],
    cache_reason: str = "",
)

    Where a view's data came from and how far it was checked, as the load reported it.

    Attributes:

    • source (str) –

      The load's source as the helper reported it (e.g. "disk", "memory", "merged").

    • loaded_at (float | None) –

      When it was loaded (wall-clock time, s since the epoch); None if unknown.

    • checked_at (float | None) –

      When it was last checked against the folder (wall-clock time); None: never.

    • verified (bool) –

      False while the data is shown from the disk cache, not yet checked against the folder.

    • unsettled_files (int) –

      TXY files left out because they were still being written.

    • failed_files (int) –

      TXY files that couldn't be read.

    • problematic (tuple[int, ...]) –

      Shots with unreadable rows (those rows dropped).

    • cache_reason (str) –

      The load's note on the cache: why cached data was used (e.g. "Folder not modified since cached") or why the data wasn't cached; "" for none.
