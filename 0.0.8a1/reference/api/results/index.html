    Run context and results¶

    compute gets an AnalysisContext: the read-only data (view), the plot's parameter values (parameters), the physical constants the run uses, and a way to stop when the user cancels (check, cancelled). render and update get an AnalysisResult, whose data is what compute returned, together with the record the plot dock shows.

    helab.analysis.results.AnalysisContext dataclass ¶

    AnalysisContext(
    job_id: str,
    action: str,
    view: DatasetView,
    parameters: Mapping[str, Any],
    analysis: AnalysisIdentity,
    cancel_event: Event = threading.Event(),
    coverage: Coverage | None = None,
    constants: Mapping[str, Mapping[str, float]] = (
        lambda: MappingProxyType({})
    )(),
    resolved_constants: ResolvedConstants | None = None,
    constant_keys: tuple[str, ...] = (),
    owner: str = "",
    live: bool = False,
    unused: frozenset[str] = frozenset(),
    to_cache: bool = False,
)

    Everything a run gets: an immutable dataset view and its effective parameters, never the tab. cancelled() lets a long computation stop early.

    compute receives it as context; it is immutable and holds no Qt object.

    Attributes:

    • job_id (str) –

      The run's ID.

    • action (str) –

      The action that runs (one of the script's get_actions).

    • view (DatasetView) –

      The data, a read-only DatasetView.

    • parameters (Mapping[str, Any]) –

      Every declared parameter's value, checked and clamped, defaults filled in.

    • analysis (AnalysisIdentity) –

      The script's identity (its ID, version and file hash).

    • cancel_event (Event) –

      Set when the run is cancelled (read it through cancelled or check).

    • coverage (Coverage | None) –

      The shots the run uses (DatasetAnalysis.covered_shots); None: all of the view's (covered).

    • constants (Mapping[str, Mapping[str, float]]) –

      The lab and folder layers of the physical constants, as {"lab": {key: value}, "folder": {...}}, taken when the run started.

    • resolved_constants (ResolvedConstants | None) –

      Those layers with the plot's own values, resolved when the run was submitted, for an analysis that uses constants; None otherwise. compute reads its constants here.

    • constant_keys (tuple[str, ...]) –

      The constants the analysis uses, which the record names.

    • owner (str) –

      The plot that asked for the run ("" for a run no plot asked for, e.g. a test). An analysis may keep per-plot state under it (dropped in DatasetAnalysis.plot_closed).

    • live (bool) –

      True for a rerun following Live rather than one the user asked for: a costly analysis may do less then and say so.

    • unused (frozenset[str]) –

      The parameters not in use under parameters (hidden by their when or shown_with), left out of the result's reuse key.

    • to_cache (bool) –

      Whether the completed result may be saved in the disk cache.

    covered property ¶

    covered: Coverage

    The shots the run uses, with their fingerprints and origins (coverage, else all).

    cancelled ¶

    cancelled() -> bool

    Whether the run was cancelled: a long compute checks it and returns early (or calls check).

    check ¶

    check() -> None

    Stop here (raise Cancelled) if the run was cancelled: call between phases.

    helab.analysis.results.AnalysisResult dataclass ¶

    AnalysisResult(
    job_id: str,
    action: str,
    analysis: AnalysisIdentity,
    input: ViewKey,
    parameters: Mapping[str, Any],
    state: State,
    data: Any = None,
    error: str = "",
    started_at: float = 0.0,
    finished_at: float = 0.0,
    policy: str = RAM_ONLY,
    coverage: Coverage = Coverage(),
    input_signature: str = "",
    constant_layers: Mapping[str, Mapping[str, float]] = (
        lambda: MappingProxyType({})
    )(),
    resolved_constants: ResolvedConstants | None = None,
    constant_keys: tuple[str, ...] = (),
    found: Mapping[str, Any] = (
        lambda: MappingProxyType({})
    )(),
    owner: str = "",
    unused: frozenset[str] = frozenset(),
    source: str = COMPUTED,
    outdated: tuple[str, ...] = (),
    packed: bytes | None = None,
    packing_error: str = "",
)

    A run's outcome and its record: what render draws and what the plot dock's tooltip shows.

    Attributes:

    • job_id (str) –

      The run's ID.

    • action (str) –

      The action that ran.

    • analysis (AnalysisIdentity) –

      The script's identity (its ID, version and file hash).

    • input (ViewKey) –

      The view the run used: its identity and revision (ViewKey).

    • parameters (Mapping[str, Any]) –

      Every declared parameter's value as the run used it, defaults filled in.

    • state (State) –

      "completed", "failed" or "cancelled".

    • data (Any) –

      What compute returned (None unless completed, and once the plot is released).

    • error (str) –

      Why the run failed ("" otherwise).

    • started_at (float) –

      When it started (s since the epoch).

    • finished_at (float) –

      When it ended (s since the epoch).

    • policy (str) –

      Where it is kept: in RAM only, or also in the disk cache.

    • coverage (Coverage) –

      The shots it used, with their fingerprints and origins.

    • input_signature (str) –

      The signature of the view's revision it ran on.

    • constant_layers (Mapping[str, Mapping[str, float]]) –

      The lab and folder layers of the constants the run got.

    • resolved_constants (ResolvedConstants | None) –

      What it resolved from them; None for an analysis without constants.

    • constant_keys (tuple[str, ...]) –

      The constants it used.

    • found (Mapping[str, Any]) –

      What it found or used beyond its parameters, as JSON values (DatasetAnalysis.result_found): kept in the record after the plot is released. Read-only at the top level only: don't change the lists and dicts inside.

    • owner (str) –

      The plot that asked for it.

    • unused (frozenset[str]) –

      The parameters it didn't use, left out of reuse_key.

    • source (str) –

      "" for a result computed now; "disk" for one read back from the disk cache.

    • outdated (tuple[str, ...]) –

      For one read back from the disk cache, what no longer matches the run asked for (empty: an exact match).

    • packed (bytes | None) –

      Its data packed for the disk cache, when it may be saved; None otherwise.

    • packing_error (str) –

      Why its data couldn't be packed ("" otherwise).

    constants_record property ¶

    constants_record: dict[str, Any] | None

    The constants the run used, as JSON values: for an analysis that declares constants (DatasetAnalysis.constant_keys), its lab and folder layers and what it resolved (ResolvedConstants.as_record), of its constant_keys only (all without); None for one that doesn't, so a lab or folder change of a value it doesn't use never makes its results look different. A layer with none of those keys is left out.

    reuse_key ¶

    reuse_key() -> dict[str, Any]

    What a later reuse of this result must match, as JSON values: a saved result's lookup key (result_cache.lookup_key). What the run decided beyond its parameters and input, which a reuse must match too, comes from found["reuse"] when the script gives it (DatasetAnalysis.result_found; e.g. a box kept from an earlier run of the plot). The parameters are those in use (not unused: a hidden setting never changes the key).

    describe ¶

    describe(parameters_text: str = '') -> str

    The record, one item per line, for a plot dock's tooltip.

    The TXY shots a run used, ascending, with their fingerprints (those the view knew) and, for those read from HeLab's TXY, their origins (helab:<profile hash>).

    The view's shots (default: all of them); numbers the view lacks are left out.

    view's shots (or those of them chosen) against this coverage.

    text ¶

    text() -> str

    60 shots (1–60), or no shots, for a record.

    to_json ¶

    to_json() -> dict[str, Any]

    Origins only when some shot has one: MATLAB's TXY alone keep the key they had.

    helab.analysis.results.CoverageDiff dataclass ¶

    How a view differs from a result's coverage: shots it has that the run didn't use (new), used shots whose fingerprints differ now (changed), used shots it lacks (gone).

    current property ¶

    current: bool

    Whether the view holds exactly the shots the run used, unchanged.
