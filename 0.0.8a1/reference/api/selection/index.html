    Shot selection and view range¶

    helab.analysis.selection ¶

    Parameters every plot shares: which shots go in (Shots), the view range (auto-crop or manual T/X/Y bounds) and highlighting the newest shot, with the helpers that apply them.

    SHOTS_GROUP module-attribute ¶

    SHOTS_GROUP = 'Shots'

    The settings section of the Shots parameters.

    SHOT_SPECS module-attribute ¶

    SHOT_SPECS: tuple[ParameterSpec, ...] = (
    SHOTS,
    FIRST_SHOT,
    LAST_SHOTS,
    LAST_SHOT,
)

    The Shots parameters (all, the last N or a range, from a first shot): add them to an analysis's parameters and read the choice with select_shots.

    NEWEST_COLOURS module-attribute ¶

    NEWEST_COLOURS = {
    "red": (214, 39, 40),
    "orange": (255, 127, 14),
    "magenta": (200, 30, 180),
    "green": (44, 160, 44),
    "black": (0, 0, 0),
}

    The colours a plot may draw the newest shot's events in, by name (RGB, 0–255).

    HIGHLIGHT module-attribute ¶

    HIGHLIGHT = 'highlight_newest'

    The name of the parameter that turns highlighting the newest shot on.

    NEWEST_COLOUR module-attribute ¶

    NEWEST_COLOUR = 'newest_colour'

    The name of the parameter that picks the newest shot's colour.

    RANGE_GROUP module-attribute ¶

    RANGE_GROUP = 'View range'

    The settings section of the view range parameters.

    Bounds module-attribute ¶

    Bounds = tuple[tuple[ParameterSpec, ParameterSpec], ...]

    Per axis (T, X, Y), its (min, max) parameters.

    BOUNDS module-attribute ¶

    BOUNDS: Bounds = bounds_specs(None)

    The manual bounds shown with the prefix that suits each value ("Basic plots v1").

    FIXED_BOUNDS module-attribute ¶

    FIXED_BOUNDS: Bounds = bounds_specs('m')

    The manual bounds shown in ms and mm (the DLD port's plots).

    SI_PREFIXES module-attribute ¶

    SI_PREFIXES = (
    (1.0, ""),
    (0.001, "m"),
    (1e-06, "µ"),
    (1e-09, "n"),
)

    (factor, prefix) pairs range_text picks from, largest first.

    select_shots ¶

    select_shots(
    view: DatasetView, values: Mapping[str, Any]
) -> tuple[int, ...]

    The view's shot numbers the Shots parameters choose, ascending: those from the first shot on, then all of them, the last N or those up to the last shot.

    shots_brief ¶

    shots_brief(values: Mapping[str, Any]) -> str

    The Shots setting in a few words for the dock's settings line; "" for all shots: shots 20–last, last 10 shots, last 10 shots from shot 20, shots up to 45, shots 20–45, shot 20, or no shots: To shot 10 is below From shot 20.

    selection_text ¶

    selection_text(
    view: DatasetView, values: Mapping[str, Any]
) -> str

    Which shots a run used, for the dock's first line: shots 51–60 (10 of 60); when none, and From shot is past the last shot loaded, it says so.

    shots_text ¶

    shots_text(selected: Sequence[int], total: int) -> str

    60 shots, or which of them when not all: shots 5–20 (16 of 60), shot 9 (1 of 60).

    newest_specs ¶

    newest_specs(
    group: str,
) -> tuple[ParameterSpec, ParameterSpec]

    Highlight the newest shot (off by default) and its colour, in a plot's group.

    newest_shot ¶

    newest_shot(
    values: Mapping[str, Any], shots: Sequence[int]
) -> int | None

    The shot to highlight: the highest of shots when highlighting is on (else None).

    newest_events ¶

    newest_events(
    view: DatasetView, shot: int | None
) -> Events

    The highlighted shot's T/X/Y events ((0, 3) for none).

    newest_colour ¶

    newest_colour(
    values: Mapping[str, Any],
) -> tuple[int, int, int]

    The newest shot's colour (RGB, 0–255) chosen in values; red when unset or unknown.

    newest_brief ¶

    newest_brief(values: Mapping[str, Any]) -> str

    newest shot in red for the dock's settings line, or "" when off.

    bounds_specs ¶

    bounds_specs(unit_prefix: str | None) -> Bounds

    Each axis's manual (min, max), in s and m: shown with the prefix that suits the value (None), or always with unit_prefix ("m": T in ms, X and Y in mm, digits grouped).

    keep_spec ¶

    keep_spec(tip: str) -> ParameterSpec

    The auto-crop share, with the plot's own description of what it crops.

    range_specs ¶

    range_specs(
    keep_tip: str, fixed: bool = False
) -> tuple[ParameterSpec, ...]

    The View range group; fixed: its bounds shown in ms and mm (the DLD port's plots).

    manual ¶

    manual(values: Mapping[str, Any]) -> bool

    Whether values choose the manual view range (else auto-crop).

    keep_fraction ¶

    keep_fraction(values: Mapping[str, Any]) -> float

    The share of events auto-crop keeps, as a fraction (0.99 for 99 %).

    manual_bounds ¶

    manual_bounds(
    values: Mapping[str, Any],
) -> tuple[tuple[float, float] | None, ...]

    Per axis, the (min, max) the user set, or None for that axis's full extent: when min = max (unset), and when min > max (reversed), which range_warnings then reports.

    range_text ¶

    range_text(axis: int, low: float, high: float) -> str

    T 3.84–3.87 s, X −2–3.5 mm: one prefix for both ends, from the larger magnitude ("Basic plots v1"; the DLD port's plots use display_units.range_text, always ms and mm).

    range_brief ¶

    range_brief(
    values: Mapping[str, Any], fixed: bool = False
) -> str

    The view range in a few words: auto-crop 99 %, or the manual axes actually set (T 3.84–3.87 s; fixed: T 3,840–3,870 ms, display_units.range_text); unset and full-extent axes are left out.

    reversed_axes ¶

    reversed_axes(values: Mapping[str, Any]) -> tuple[str, ...]

    The axes whose manual min is above their max, when the range is manual.

    range_warnings ¶

    range_warnings(
    values: Mapping[str, Any],
) -> tuple[str, ...]

    What the plot did differently from the settings: a reversed manual axis uses its full extent. Shown on the figure, in the dock's source line and record, and in the settings tab.

    manual_box ¶

    manual_box(
    events: Events, values: Mapping[str, Any]
) -> CropBox

    The box of the manual bounds, each unset axis spanning its events' full extent.
