## DLD analyses

**DLD analyses** (`roadmaps/dld-front-panel-port.md`): **constants** come in three layers over the table in `helab/analysis/physics.py` (`CONSTANTS`: unit, source, level lab or folder, `unconfirmed`, read-only `codata`, `shown_only`, `optional` rows left unset until measured, `signed`, coded `choices`; `resolve` → a frozen, hashable `ResolvedConstants` with each value's origin and notes, e.g. a hand-set fall time more than 0.1 % from √(2h/g), which counts only at the fall distance's layer or a more specific one): Settings → Lab parameters (`helab/views/LabParametersTab.py`, `helab/utils/lab_parameters.py`, `FolderCache.lab_constants`), folder constants (Caching) and a plot's Constants group (`constant_layers.constants_specs`: "lab/folder" or "this plot" per key). An analysis declares the keys it uses (`constant_keys`, by default its Constants group's; `run_constant_keys` narrows them for a run's settings, e.g. the trap's only with a bimodal fit; `run_constants` gives None for a run that uses none). A run gets the lab and folder layers in `AnalysisContext.constants` and `resolved_constants`, resolved on the GUI thread at submit; its result records them once (the record's Constants line, and `reuse_key` with the analysis's keys only), and a later lab or folder change of one of its keys marks its plot amber "constants changed (…): Rerun to use them" until Rerun or the next Live run. Unset optional rows (release time t_r, arrival at rest t_a, trap origin x₀/y₀) resolve to nan with origin "detected" ("from the data"); a plot takes t_r = t_a − t_f with its own fall time (`release.layer_release_time`), never another plot's t_r.

## Shared numerics

**Shared numerics** in `helab/analysis/` (NumPy/SciPy, no Qt; failures are results with notes, never exceptions): `fits.py` (`fit_histogram` → `FitResult` ± SE: Poisson maximum likelihood by default, the model averaged over each bin, offset ≥ 0 on raw counts, `edges=` for unequal bins; `MODELS`: Gaussian, the arrival-time thermal profile, TF, Bose g_5/2, bimodal TF + Gaussian or Bose with p = 2 or 3/2, R/σ_th capped per axis, `choose_condensate`), `estimates.py` (`Estimate`, `format_uncertainty`, `pooled_mean_and_std`, `sewm`), `profiles.py` (rates per shot, smoothing in bins of σ/5, `fit_axis`; a smoothed-curve fit smooths the model too), `bec.py` and `bec_readout.py` (Tc, μ, TF radii, n0 and the QE checks from a fit), `velocity.py` (z up, v_z = ½ g τ − h/τ at release, TXY column order, never an XY rotation; m/s, ħk/m, 2ħk/m), `release.py` (release time and trap origin from one cloud; `bootstrap_release_time`; `run_velocity_source`, the one t_r and origin rule both velocity plots follow), `peaks.py`, `bootstrap.py` (`bootstrap_shots`: 1000 resamples, seed 0, 68.27 % percentile interval; `shot_means`), `spectrum.py`, `correlations.py` (g², `PairCounts` for Live; `correlate(errors="jackknife")` for errors without a bootstrap), `trends.py` (per-shot estimates, `ShotCache`, low-count rules), `masks.py` and `hotspots.py`.

## Units

**Units** (Tony, 2026-10-20; the DLD port's plots, Basic plots v1 keeps s and m with SI prefixes, `selection.range_brief` / `range_specs` without `fixed`): T always in ms and X/Y in mm, digits grouped with "," and "." whatever the locale (`1,234.5678 ms`; `helab/analysis/display_units.py`, tick labels `plot_axes.GroupedAxis`), on axes, titles, records and settings (`ParameterSpec.unit_prefix`: shown in ms or mm, stored in s and m); frequencies, gaps between shots and other constants keep SI prefixes.

## Hooks

**Hooks:** `result_found` becomes the result's read-only `found` (kept by a release; one that raises is logged and gives `{}`), whose `"reuse"` entry joins `reuse_key`; `result_record` (default `found["record_lines"]`) and `describe_result` add to the dock's record and settings line; `AnalysisContext.owner` (the plot) keys per-plot state, which `plot_closed` drops, `plot_released` drops when the budget releases the plot (it may run again) and `plot_buffers` counts toward the RAM budget (Correlations' pair counts); `AnalysisContext.live` marks a rerun following Live (costly plots skip their shot bootstrap then and say so; `rerun_after_live` says so of a result, and when Live stops the plot runs once more on that result's shots); `AnalysisContext.unused` (hidden settings) stays out of the reuse key; hooks that raise are logged, with a fallback.

## Saved results

**Saved results** (R2): `cache_supported` (default off; on for Correlations and Release time), `cache_types` (dataclasses, enums, `result_codec.Reducer`s such as `result_types.FIT_MODEL`), `cache_pack`/`cache_unpack` (default: the codec), `cache_holds_state` (kept plot state: no lookup) and `cache_result` (a fresh plot's result: may be saved). `AnalysisQueue.prepare` and `enqueue` split `submit`; a run to be saved has its result packed on the worker (`AnalysisResult.packed`). `result_cache`, `result_codec` and `result_types` are Qt-free. The source line marks reuse ("disk cache reuse on", "saved in disk cache", "from disk cache, computed …", "saved result of …, outdated"). A folder with saved results that reuse will use shows REPORT after the data cache's badge, and its tooltip and Folder details' cache line say "Cached analysis: N results, X MB" (listing counts, memory only).

## Mask

**Mask** (`helab/analysis/masks.py`): none, a preset ("earlier detector (2020)": Core's `hotspot_mask.m` 2020 list, unrotated; "current detector": empty until D15) or custom circles `x, y, r[, keep|cut]` in mm; an event stays inside every keep and outside every cut circle (strictly closer than r); XY only, before the view range; in the reuse key and record; unreadable circles fail the run.

## Plots of the port

**Plots of the port** (group "DLD Front Panel Port", `helab/scripts/dld/`, PyQtGraph only, no Drawing › Library; the 3D scatter Plotly): T, X, Y histograms (counts or a rate per shot, smoothing, a Fits page off by default: Gaussian, arrival-time, bimodal TF² or TF^3/2 + Gaussian or Bose with the condensate decision, Show BEC properties); Density images (XY/XT/YT, blur, colour compression in the colour map only, and Find hot spots, the D15 placeholder, whose circles Copy circles offers and nothing applies); Mean X, Y against T and T spectrum (peak lists); Shot times (raw-file times, TXY-time shots amber); Shot trends (per shot: counts, centre, width and temperature, moving mean ± SD, low-count flags, Notify during Live off by default); Release time (Use for this folder… saves the arrival t_a and the origin to the plotted folder); Velocity distributions (v_z, v_x, v_y histograms and a 2D density, mm/s by default); Correlations (`correlations_plot.py`, D12/D13: 1D or radial g², collinear or back-to-back about v₀, Re-centre each shot standing in for D13's halo centring, per-mode defaults, velocity settings in mm/s whatever the drawing unit; one `PairCounts` and in-shot cache per plot, so Live counts only new shots, restarting when t_r, h, g, the origin, the mask or the view box change, and a detection within its SE of the plot's previous one is kept; a time budget stops adding shots and the next run continues; Live reruns skip the bootstrap and use jackknife errors, said so). A Live rerun keeps the plot's last t_r detection and auto-crop box while the folder's data (`DatasetView.chain_key`: TXY source and choice, chain, profile hashes), settings and constants are the same (`KeptRuns`); a run the user starts, another plot, load or TXY choice finds its own (plots-3); Correlations' kept box and detection use the same key. Live waits 2 s for the histograms, Density images, Mean X, Y and T spectrum, 5 s for Release time, Velocity distributions, Correlations and the 3D scatter; the others rerun on every shot.

## Legacy MATLAB references

**Legacy MATLAB references** (none is part of the Python package or needed to run HeLab): `legacy/tdc_autoconverter` is the one git submodule (`HeBECANU/tdc_autoconverter`), the lab's MATLAB TDC data auto-converter that turns raw `d*.txt` into `d_txy_forc*.txt`; the reference for a converter port is `tdc_auto_convert.m` and, in `lib/`, `dld_raw_to_txy_counts.m`, `dld_read_5channels_reconst_multi_imp.m` and `txy_importer.m`. The other two are cloned by hand at the commits the port was read from (README, "Legacy references"; gitignored since Q6.4, when a nested submodule of DLD_front_panel stopped Dependabot's scan). `legacy/Momentum_Bells_test` (`HeBECANU/Momentum_Bells_test`, branch `OneDrive-Yogesh`, commit `fdfcb6b`, ~400 MB) is the lab's MATLAB halo/momentum analysis, the reference for porting analyses such as `monitor_momentum.m` into plots. `legacy/DLD_front_panel` (`HeBECANU/DLD_front_panel`, branch `LaserMac-BECMachine-cloudstor`, commit `6c7352c`, ~40 MB checked out with its nested `Core_BEC_Analysis` submodules) is the lab's earlier MATLAB GUI for basic delay-line-detector data visualization and analysis; features to port: `roadmaps/dld-front-panel-port.md`.
