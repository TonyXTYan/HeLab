## Settings persistence

**Settings persistence:** Uses `QSettings` with org `ANU_HE_BEC_GROUP`, app `HeLab`, opened only by `app_settings()` (`helab/utils/settings_store.py`; `tests/test_settings_store.py` fails if anything else in `helab/` constructs the native store, helpers aside, which reopen it from `settings_spec` with `open_settings`, both in `helab/utils/cache_setting.py`). macOS plist: `~/Library/Preferences/com.anu-he-bec-group.HeLab.plist` (Qt derives the name from the org). Tests must not create native settings stores: `app_settings()` gives each test its own ini (`HELAB_TEST_SETTINGS_FILE`, `tests/conftest.py`), or pass a tmp-dir `QSettings(path, IniFormat)`. Lab parameters are `lab_constants/<key>` in SI units (`helab/utils/lab_parameters.py`): only values the user set (Restore removes the key, so a corrected default applies), never CODATA rows; Reset all settings clears them. The plots to reopen are an arrangement record under `open_plots` (Reset all settings clears it); presets are in the disk cache store (Caching), not QSettings. `reuse_saved_results` (Settings → Cache › Reuse saved analysis results, default off since Q27.1: a new key, so the old `result_reuse`, saved on, no longer counts and is left unread; off: no lookups and no saves, and saved results stay until cleared) is a `settings_defaults.py` row. So is `work_offline` (File › Work Offline, default off, remembered across restarts). `HelabMainWindow` reads them through `app_settings()`, so tests that build a real window see their own ini, never the developer's settings. Every key HeLab reads is in `helab/utils/settings_defaults.py` (key, type, default, description; the `lab_constants/` prefix; `RETIRED` keys, removed when Settings saves), and reads go through `read_setting` (`tests/test_settings_defaults.py`). Read numbers untyped: PyQt's `type=int` is 32-bit and reads 8 GB wrong, so `read_setting` refuses typed reads of number rows.

## Converter rows

**Converter rows** (stage 4): `converted_txy_output` (cache/temp), `convert_profile` (default `matlab-2019`) and `convert_backend` (default `numpy`), edited in Settings → TXY converter and read by `read_convert_output`/`read_convert_profile`/`read_convert_backend` (`helab/utils/constants.py`); user profiles are files in `<app folder>/profiles`, not settings. `txy_source` (default `helab-priority`; `read_txy_source`; Settings → TXY converter "Tabs and Live read", applies when a folder loads again). Live: `live_launch_folder` (one folder that starts Live and auto-convert at launch, `live_launch`; `live_launch_folders`, the old list, is read once to move its first folder over, then removed, A23.3) and `convert_low_hits` (100; 0 never).
